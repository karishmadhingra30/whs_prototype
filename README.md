# Women's Health Search (WHS) prototype

A question-answering tool for endometriosis. A user asks a question and gets an
answer grounded in published research, with caveats such as which populations
were studied. Information only, not diagnosis.

Built as the final project for PH 290 (GenAI for Health), UC Berkeley.
